## Getting Setup

### Repository

Before starting this coursework, [fork and clone this repository](https://github.com/Sigma-Labs-XYZ/Coursework-Data-Analysis-Fundamentals-Week-1).

All code that you produce during this week should be stored in your repository.

### Required Software

:::info Task

Install **DBeaver Community Edition**.

1. Visit [dbeaver.io/download](https://dbeaver.io/download/) and download the **Community Edition** for your operating system.
2. Run the installer and follow the on-screen instructions.
3. Open DBeaver to confirm it launches without errors.

:::
